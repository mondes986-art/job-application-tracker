# Job Application Tracker

A web-based application built to help job seekers manage and track their job applications in one centralised system.

## Overview

The Job Application Tracker allows users to record, manage and monitor their job applications throughout the recruitment process.

Users can add applications, update application information, view application details, delete applications, and filter applications based on company, position and status.

## Features

- Add new job applications
- View all job applications
- View application details
- Edit existing applications
- Delete applications
- Search applications by company or position
- Filter applications by status
- Dashboard showing application statistics
- Responsive web interface

## Dashboard

The dashboard provides an overview of:

- Total applications
- Applications submitted
- Interviews
- Assessments
- Offers
- Rejected applications
